Spring models

Every spring model describes the soil reaction at a depth along the pile as a function of the local pile displacement v (and, for PISA and Tott-Buswell, the rotation ψ or θ). How these curves are turned into node springs is described in Calculation method. The models are in methods/spring_models/.

Notation: z depth below mudline, D pile diameter, σ'_v vertical effective stress (integrated from gamma_eff of all layers above), y or v lateral displacement. Units in the formulas: kN, m, kPa.

Layered soil: every half element is evaluated with the layer at its mid-depth; z is always measured from the mudline (not from the top of the layer), and γ'·z of single-layer formulas is replaced by σ'_v.

1. API (sand) — API

API RP 2GEO / RP 2A, hyperbolic tangent curve (Murchison & O'Neill 1984):

p = A · p_u · tanh( k·z · y / (A · p_u) )

p_u = min( (C1·z + C2·D)·σ'_v ,  C3·D·σ'_v )
A   = max(3.0 − 0.8·z/D, 0.9)   static
A   = 0.9                        cyclic

C1, C2, C3 follow from φ with the API formulas (α = φ/2, β = 45° + φ/2, K0 = 0.4, Ka = tan²(45° − φ/2)).

The initial modulus of subgrade reaction k is taken from soil.csv (k [MN/m³]) or, if empty, interpolated linearly from the API chart for submerged sand: 5.4 / 16.3 / 33.9 MN/m³ at φ = 29 / 33 / 36° (constant outside). This is a coarse fit; Thieken et al. (2015) use k = 0.008085·φ^2.45 − 26.09 MN/m³ (Augustesen et al. 2009), which gives e.g. 41.9 MN/m³ at φ = 40°. Give k explicitly when a better value is known.

Parameters: gamma_eff, phi (required), k (optional).

2. Matlock (clay) — all models

Matlock (1970) soft clay, used for every clay layer by every model (ClayPY in base.py):

p_u = min(3·s_u + σ'_v + J·s_u·z/D , 9·s_u) · D
y_c = 2.5 · ε50 · D

static:  p/p_u = 0.5·(y/y_c)^(1/3)  up to y = 8·y_c, then 1.0
cyclic:  as static up to 3·y_c (p/p_u = 0.72); beyond that 0.72 for
         z ≥ X_R, otherwise linear decrease to 0.72·z/X_R at 15·y_c
X_R = 6·D / (γ'·D/s_u + J)

Parameters: gamma_eff, su (top-bottom for a linear variation), eps50 (default 0.01), J (default 0.5).

PISA and Thieken are formulated for sand only; their clay layers use these curves (lateral springs only) with a warning.

3. Kallehave et al. (2012) — KALLEHAVE

API sand curve with a modified initial slope (eq. 7 in Thieken et al. 2015):

E_py = k · z0 · (z/z0)^m · (D/D0)^0.5
z0 = 2.5 m,  D0 = 0.61 m,  m = 0.6

k as for API. Derived from measured stiffnesses of operating monopiles under small loads; stiffer than API for large diameters. According to Thieken et al. (2015) only valid for small head displacements (< 0.0005·D).

Parameters: as API.

4. Sørensen et al. (2010) — SORENSEN

API sand curve with a modified initial slope (eq. 5 in Thieken et al. 2015):

E_py = a · (z/z_ref)^b · (D/D_ref)^c · φ^d
a = 50 MPa, b = 0.6, c = 0.5, d = 3.6, z_ref = D_ref = 1 m, φ in radians

Softer than API for large diameters. Note: the 2012 version of Sørensen's formulation (with E_s instead of φ), which Thieken et al. (2015) evaluate in their figures, is not implemented.

Parameters: gamma_eff, phi.

5. Thieken et al. (2015) — THIEKEN

Thieken, K., Achmus, M., Lemke, K. (2015). A new static p-y approach for piles with arbitrary dimensions in sand. geotechnik 38(4), 267–288.

Ultimate resistance (DIN 4085, eqs. 17–19, 29), δ_p = −2/3·φ (angles in rad):

K_pgh = (1+sin φ)/(1−sin φ) · (1 − 0.53·δ_p)^(0.26 + 5.96·φ) / sqrt(1 + tan²δ_p)
p_C,basic = 11/16 · σ'_v · sqrt(z) · K_pgh · (1 + 2·tan φ) · sqrt(D)
p_C = p_C,basic · max(3 − 2·(z/(2.5·D))^0.25 , 1)

Basic curve with stretching factor SF (eqs. 20–28):

y_B = p_C/(E_s·SF),  y_C = 4·y_B,  y_A = 0.005·D·y_B,  p_B = R_B·p_C
R_B = max(0.63 − 0.33·(z/D / 7.5)^0.5 , 0.35)
y ≤ y_B:       p = p_B·(y/y_B)^(1/n) ≤ E0_py·y
y_B < y < y_C: linear from p_B to p_C
y ≥ y_C:       p = p_C
n  = n_A for y ≥ y_A,  n0 + (n_A − n0)·(y/y_A)^0.25 for y < y_A
n_A = 2.4 − 0.08·(φ[°] − 30)
n0  = log(10⁻⁵·D / y_B) / log(E0_py·10⁻⁵·D / p_B)
E0_py = G0 · 2(1−ν²)/(1−ν−2ν²) · SF

The text of the paper gives y_A = 0.005·p_C/(E_s·SF), Fig. 14 an additional factor D; the Fig. 14 version is used.

Soil stiffness (σ_m = σ'_v (1+2k0)/3, k0 = 1 − sin φ):

E_s = es_ref · (σ_m / 100 kPa)^λ_ES         (paper: es_ref = κ · 100 kPa)
G0  from g0 / g0_ref + λ_G0 / Hardin & Black (see user guide)
                                             (paper: G0 = 6900·(2.17−e)²/(1+e)·σ_m^0.5)

Stretching factor SF = SF_bend + SF_tip from the deflection line of the previous run (eqs. 30–35; L embedded length, z_y0 rotation point, z_ymin depth of the largest backward deflection):

z ≤ z_y0:           SF_bend = 2.3·y/y_max + 0.3
z_y0 < z ≤ z_ymin:  SF_bend = 1.2·y/y_min + 0.3
z > z_ymin:         SF_bend = max(1.2·y/y_min + 0.3 , 1.0)
z ≥ L − 2D:         SF_tip  = 5·((z−L)/(2D) + 1)^5
z ≥ L − 0.1D:       SF_tip  = 5·((z−L)/(2D) + 1)^5 + 3

The first run of a load level without prediction uses SF = 1 (basic curves); the model is then iterated until the deflection line no longer changes. The stretching factors at every node are written to pile_profile.csv (SF_bend, SF_tip, SF).

Parameters: gamma_eff, phi, nu, es_ref, lambda_es and G0 (required, no defaults). Reference values of the paper (Table 1):

νE_s,ref [MPa]λ_ESG0,ref [MPa]λ_G0φ [°]γ' [kN/m³]

6. PISA sand model — PISA_SAND

Burd, H. J. et al. (2020). PISA design model for monopiles for offshore wind turbines: application to a marine sand. Géotechnique 70(11), 1048–1066.

Four soil reaction components, each a conic function of a normalised displacement or rotation (eqs. 1–5), with the parameters of the General Dunkirk Sand Model (GDSM, Table 6) as functions of D_R, z/D, z/L and L/D:

ComponentNormalisationSpring
distributed lateral load p(v)p̄ = p/(σ'_v·D), v̄ = v·G0/(D·σ'_v)lateral, every node
distributed moment m(ψ)m̄ = m/(|p|·D), ψ̄ = ψ·G0/σ'_vrotational, every node
base shear H_B(v)H̄ = H_B/(σ'_v·D²)lateral, pile tip
base moment M_B(ψ)M̄ = M_B/(σ'_v·D³)rotational, pile tip

Implementation details:

  • Diameter: the PISA papers use one D for the thin-walled section properties (I = π·D³·t/8, A = π·D·t) and in all formulas. This is the mean (mid-surface) diameter: D from pile.csv with DIAMETER_REFERENCE = "mid", D − t with "outer". To reproduce the papers, use "mid" with their D (Table 7 within 0.2 %; with their D taken as outer diameter 1.2–1.6 % lower, see Verification).
  • The distributed moment depends on the current lateral load p(v) (eq. 6); it is evaluated with v of the previous run, so the model is iterative. The first run without a state uses p_u (upper bound).
  • G0 after Hardin & Black (eq. 7) with B = 875 for Dunkirk sand (e0 = 0.741 / 0.685 / 0.629 / 0.573 for D_R = 45 / 60 / 75 / 90 %), or one of the other G0 inputs. k0 = 0.4 without φ (Dunkirk value).
  • Calibration space: 45 % ≤ D_R ≤ 90 %, 2 ≤ L/D ≤ 6, 5 ≤ h/D ≤ 15, 5 m ≤ D ≤ 10 m, homogeneous sand, monotonic drained loading. Outside of it, D_R, z/D and L/D are clamped to the limits and a warning is given.

Parameters: gamma_eff, dr, G0 input, phi (optional).

7. PISA clay model — PISA_CLAY

Byrne, B. W. et al. (2020). PISA design model for monopiles for offshore wind turbines: application to a stiff glacial clay till. Géotechnique 70(11), 1030–1047.

Same four components and conic function as the sand model, normalised with the undrained shear strength s_u and G0 (Table 3):

ComponentNormalisationSpring
distributed lateral load p(v)p̄ = p/(s_u·D), v̄ = v·G0/(s_u·D)lateral, every node
distributed moment m(ψ)m̄ = m/(s_u·D²), ψ̄ = ψ·G0/s_urotational, every node
base shear H_B(v)H̄ = H_B/(s_u·D²)lateral, pile tip
base moment M_B(ψ)M̄ = M_B/(s_u·D³)rotational, pile tip

cowden (default): stiff overconsolidated glacial clay till, second-stage calibration (Byrne et al. 2020, Table 4), which the paper recommends for design:

Implementation details:

  • Not iterative. Unlike in sand, the distributed moment does not depend on p, so the springs depend on the depth only. Under force control, all load levels run in one Abaqus job.
  • Diameter: D is the mid-surface diameter, as in the sand model.
  • s_u and G0 are taken at the mid-depth of every half element (base springs: at the tip). s_u comes from the su column (top-bottom allowed). G0 comes from g0, the power law or Hardin & Black, as in the sand model. The paper uses G0 = 1100·p′, i.e. the power law with g0_ref = 110 MPa and lambda_g0 = 1 if K0 = 1 − sin φ fits the site. Otherwise give g0 directly.
  • Calibration space: 2 ≤ L/D ≤ 6, 5 ≤ h/D ≤ 15, 5 m ≤ D ≤ 10 m. z/D and L/D are clamped to it (warning). The parameters belong to the s_u and G0 profiles of the representative Cowden site (undrained loading). Other clays or strongly different profiles need a separate calibration (paper, Discussion).
  • Sand layers are not covered and give an error (use PISA for layered sand/clay profiles, section 8).

Parameters: su, pisa_clay (optional, default cowden), G0 input, phi (optional, k0 for G0); gamma_eff is required by soil.csv but only used for G0.

8. PISA for layered soils — PISA

Burd, H. J. et al. (2020b). Application of the PISA design model to monopiles embedded in layered soils. Géotechnique 70(11), 1067–1082.

The reaction curves calibrated for homogeneous soils are applied locally at every level of the pile. The soil type of the layer selects the framework (Table 11 of the paper):

LayerReaction curvesNormalisation
sandGDSM (section 6), dr of the layerσ′_v, G0; m = |p|·D·m̄
clayCowden till or Bothkennar clay (section 7), pisa_clays_u, G0

How it works:

  • Local soil values: every half element uses σ′_v, s_u and G0 at its own mid-depth.
  • Base springs use the layer at the pile tip. Layers below the tip have no influence, as in the paper.
  • Nodes lie at every layer boundary, so a node on a boundary gets half its spring from each layer.
  • Iteration: the model is iterative if the profile contains sand (the sand distributed moment depends on p); a pure clay profile is not.
  • Equivalence: for a homogeneous profile, PISA gives exactly the same springs as PISA_SAND or PISA_CLAY.

Validity (paper, 35 layered cases against 3D finite-element analyses):

  • Small displacements: good in all cases (η_sd ≥ 0.9).
  • Ultimate displacement: mostly good, but less accurate for combinations of soft clay (Bothkennar) and very dense sand, especially for L/D = 2 (η_ult down to 0.66). The model gives a warning for such profiles (Bothkennar clay together with D_R ≥ 85 %).
  • Stiff layers below the pile tip can increase the capacity in 3D; the 1D model does not capture this.

Parameters: as for PISA_SAND in sand layers and PISA_CLAY in clay layers (PISA_COLUMNS in Input.py).

9. Tott-Buswell et al. (2024), CPT-based multi-spring model — TOTT_BUSWELL

Tott-Buswell, J., Prendergast, L. J., Gavin, K. (2024). A CPT-based multi-spring model for lateral monopile analysis under SLS conditions in sand. Ocean Engineering 293, 116642.

Four uncoupled spring types, all informed by the cone resistance q_c of a CPT profile (CPT file, see the user guide). The springs depend on the depth only, so the model is not iterative.

ComponentCurveSpring
distributed lateral load p(y)power law after Li et al. (2014), eq. 1lateral, every node
distributed moment m(θ)parabola from the vertical shaft friction, eqs. 2–7rotational, every node
base moment M_B(θ)bilinear, eqs. 8, 9rotational, pile tip
base shear H_B(y)bilinear, eqs. 10–12lateral, pile tip

p-y (γ' = gamma_eff of the layer):

p = 3.6 · D · (γ'D) · (q_c/(γ'D))^0.72 · (y/D)^0.66

No ultimate value. The curve is sampled up to y = 0.5·D and is constant beyond.

m-θ. The axial τ-w curve of the unified CPT method (Lehane et al. 2020), τ = G0·w/(2D)·(1 − w/(2w_f)), is integrated around the circumference with w = θ·D/2·cos φ:

m = a·θ − b·θ²  (θ < θ_f),   m = m_f  (θ ≥ θ_f)
a = π·D²·G0/16,   b = G0²·D²/(96·τ_f)
θ_f = 3π·τ_f/G0,  m_f = 3π²·D²·τ_f/32

τ_f    = (f_t/f_c)·(σ'_rc + Δσ'_rd)·tan δ_f,   f_t/f_c = 0.8, δ_f = 29°
σ'_rc  = (q_c/44)·A_re^0.3·max(1, H/D)^−0.4
Δσ'_rd = (q_c/10)·(q_c/σ'_v)^−0.33·(d_CPT/D),   d_CPT = 35.7 mm
A_re   = 1 − PLR·(D_i/D)²,   PLR = tanh(0.3·(D_i/d_CPT)^0.5)

H is the distance from the pile tip. τ_f is written to pile_profile.csv.

Base springs. The residual base stress q_b,res = α·q_c,r is set with TOTT_BUSWELL_ALPHA (paper: α = 0.1 recommended; 0.04 … 0.1 fitted to the field tests). q_c,r is the mean q_c from 0.25·L/D [m] above to 0.25·L/D [m] below the tip.

M_B,f = q_b,res·πD²/8 · 2D/(3π) = q_b,res·D³/12,   θ_B,f = 44.98·σ'_v,b/G0
H_B,f = πD²/4 · q_b,res · tan 35°,                y_B,f = 2·ȳ·D·σ'_v,b/G0
ȳ = (0.52 + 2.88·D_R) + (0.17 − 0.70·D_R)·L/D,    L/D limited to 2 … 6

Implementation details:

  • q_c averaging: q_c is averaged over the pile length of every spring half element (the paper averages it over its 0.05 m elements). With a strongly varying q_c, use short elements.
  • Diameters: D is the outer diameter (D + t if DIAMETER_REFERENCE = "mid"). The inner diameter is D_i = D − 2t; the paper writes D − t.
  • G0: from the g0 column of the CPT file if present, otherwise from soil.csv (g0, power law or Hardin & Black, as for PISA/Thieken).
  • D_R for the base shear: dr of the layer at the tip, 75 % (paper) if not given.
  • Clay layers: Matlock p-y (lateral only, warning); no base springs if the tip is in clay.
  • TOTT_BUSWELL_COMPONENTS selects the springs, e.g. ("p-y",) or ("p-y", "m-theta") for the comparisons of the paper.

Validity: small to medium displacements (SLS, about 0.01·D at the mudline, mudline rotation ≤ 0.25°). The model does not predict the ultimate capacity. It works best for uniform or linearly increasing q_c profiles; strongly varying profiles give a too stiff response (paper, Dunkirk tests).

Parameters: CPT file (z, qc, optional g0); in soil.csv gamma_eff, G0 input (if the CPT file has no g0), phi (optional, k0 for G0) and dr (optional).

10. Choosing a model

QuestionSuitable model
Design according to the offshore guidelinesAPI
Large-diameter monopile, realistic stiffness for all load levels (sand)Thieken, PISA
Within the PISA calibration space (Dunkirk-like sand)PISA
Stiff overconsolidated clay till (Cowden-like), within the PISA calibration spacePISA_CLAY
Layered sand/clay profiles with PISA-type soilsPISA
Foundation stiffness under very small loads onlyKallehave
Comparison with older studiesSørensen (2010)
Serviceability (SLS) of monopiles from CPT data, L/D ≈ 3 … 13TOTT_BUSWELL

Thieken et al. (2015) show that API, Kallehave and Sørensen are not generally suitable for large-diameter piles over the whole load range; the model comparison in Verification shows the differences for the reference monopile.
