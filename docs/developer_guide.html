3. Conventions

  • Units: inside Abaqus SI (N, m). Spring model curves work in kN, m, kPa and are converted to N by curve_contribution (factor 1000). Soil inputs: kN/m³, kPa, MPa (converted to kPa when read), degrees.
  • Depths: pile files: below the pile head; soil files and spring models: below the mudline (z_soil); Abaqus Z = −depth.
  • Signs: see Calculation method. Spring curves are defined for x ≥ 0 and mirrored.
  • Style: PEP 8, 79 characters per line, docstrings for every module, class and public function. Every spring model documents its soil.csv parameters in a "Soil parameters (soil.csv)" section of its module docstring.
  • Errors: invalid input raises ValueError with a message naming the file, line or setting; main.py reports it per case and continues.

4. Adding a spring model

  1. Create methods/spring_models/<name>.py with a subclass of SpringModel (or of an existing model, e.g. ApiPyModel with another sand_curve, as in kallehave.py, or of PisaModel (pisa.py) for another PISA calibration, as in pisa_clay.py): 
    from .base import SpringModel, curve_contribution, missing_parameters

class MyModel(SpringModel):
    name = "MY_MODEL"         # key in SPRING_MODEL (Input.py)
    label = "MyModel"         # results folder name
    iterative = False         # True if the curves depend on (v, psi)
    has_rotational_springs = False

    def __init__(self, pile_sections, soil_layers, mudline_depth, **_):
        super(MyModel, self).__init__(pile_sections, soil_layers,
                                      mudline_depth)
        errors = missing_parameters(soil_layers, ("phi",))
        if errors:
            raise ValueError("MY_MODEL: soil parameters in soil.csv "
                             "(%s)." % "; ".join(errors))

    def distributed_springs(self, point, node_result):
        if point.layer.soil_type != "sand":
            return self.clay_fallback(point)
        curve = ...               # object with p(y) [kN/m], y in m
        return curve_contribution(curve, point.length, x_max), None
  2. distributed_springs(point, node_result) returns (lateral, rotational) Contributions (or None) for one half element. point (SoilPoint) holds z_soil, layer, sigma_v, diameter, thickness, length; node_result is (v, ψ) of the node from the previous run (None in the first run).
  3. Optional hooks: base_springs(point, node_result) (pile tip), prepare(nodes, node_results) (e.g. evaluate the whole deflection line, see Thieken), output_columns + node_output(z_soil, diameter) for extra columns in pile_profile.csv.
  4. Register the class in SPRING_MODELS in methods/spring_models/__init__.py.
  5. Add a column block to Inputs/Input.py and to MODEL_COLUMNS (and to the Input.py of other input folders that should use the model). New soil parameters also need an entry in SOIL_OPTIONAL_COLUMNS and SoilLayer in csv_reader.py.
  6. Document the model in docs/spring_models.html and verify it against a published case.

Shared helpers in base.py: curve_contribution, matlock_contribution, SpringModel.clay_fallback, missing_parameters, small_strain_modulus, check_g0_inputs, mean_stress.

5. Extending the output

  • Per load level: LoadLevelResult (solver.py) and write_pile_head_csv.
  • Per node: ProfileRow / read_pile_profile (postprocessing.py), or a spring model's node_output.
  • Per case: case_summary (main.py) and the column list in write_summary_csv.
  • Plots: methods/plots.py, called through make_plot in main.py (errors only produce a warning).
  • Progress messages: the report function passed to run_case and the solver.

7. Testing

  • Plain Python (no Abaqus): spring models, CSV reading, mesh functions, break criteria and plots can be tested directly, e.g.

    from methods.csv_reader import SoilLayer, PileSection
from methods.spring_models import create_spring_model
m = create_spring_model("THIEKEN", [PileSection(0, 30, 5, 0.069, "S355")],
                        [SoilLayer(0, 60, "sand", 10.31, phi=40, nu=0.2,
                                   es_ref=70, lambda_es=0.5,
                                   g0_ref=106.3, lambda_g0=0.5)], 0.0)
springs = m.compute([(i + 1, 0.5 * i) for i in range(61)])

    Modules that import Abaqus (solver.py, postprocessing.py, …) can be imported after inserting dummy modules for abaqus, abaqusConstants, odbAccess etc. into sys.modules.

  • Abaqus Python (abaqus python script.py): odb evaluation (read_pile_profile) on existing results.
  • Full runs: the verification input folders in Inputs/Verification/ (about 0.5–4 minutes each), see Verification. After changes to the solver or a spring model, repeat them and compare with the tables of the verification page.
